# Baithul Madeena Backend

Laravel REST API for the Baithul Madeena ERP.

## Stack

- Laravel 13
- PHP 8.3+
- MySQL
- REST/JSON

## Development

Install dependencies:

```bash
composer install
```

Create local environment configuration:

```bash
cp .env.example .env
php artisan key:generate
```

Application-specific setup will be documented as infrastructure and domain features are added.
